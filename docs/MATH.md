# X20 用到的数学

## 1. 状态向量

在时间 `t`，程序把 20 个因子整理成一个向量：

```text
x(t) = [x₁(t), …, x₂₀(t)]ᵀ ∈ [-1, 1]²⁰.
```

归一化把不同单位放进同一个模型，也限制异常数据对结果的影响。将来做正式校准时，归一化参数只能从训练数据计算，不能偷看测试期数据。

## 2. 二次响应曲面

```text
z(x) = β₀ + βᵀx + ½xᵀHx,
p(up | x) = 1 / (1 + exp(-z)).
```

`H` 是对称矩阵，非对角项表示两个因子之间的关系。例如，一条可信度很低的利好消息，不应该和 SEC 文件确认的消息产生相同影响。

## 3. 梯度

当 `H` 对称时：

```text
∂z/∂xᵢ = βᵢ + Σⱼ Hᵢⱼxⱼ,
∇z = β + Hx.
```

页面按 `|∂z/∂xᵢ|` 排序，用它表示当前状态下各因子的局部敏感度。它不是因果证明。

## 4. 多元链式法则

每个因子都在随时间变化。模型分数的瞬时变化率是：

```text
dz/dt = Σᵢ (∂z/∂xᵢ)(dxᵢ/dt) = ∇z · ẋ.
```

偏导数很大的因子，如果此刻没有变化，对 `dz/dt` 的贡献仍然可能很小。偏导数和实际变化量必须一起看。

## 5. Hessian 和压力测试

因为这里使用二次曲面，Hessian 就是 `H`。给状态加入一个冲击 `h`：

```text
z(x + h) - z(x) = ∇z(x)·h + ½hᵀHh.
```

其中二阶项表示因子之间的共同影响。这是普通线性加权分数看不到的部分。

## 6. 区间怎么得到

v0.1 会在历史较短、数据缺失较多或波动较高时主动扩大区间：

```text
u = u₀ + history_penalty + coverage_penalty + volatility_penalty.
90% interval = expected_return ± 1.645u.
```

这只是工程上的不确定性范围，还不是经过统计校准的置信区间。v0.3 需要用 purged walk-forward evaluation 检查它的实际覆盖率。

## 7. 怎么检查公式实现

`tests/test_model.py` 会把解析梯度与中心有限差分结果对比，并检查二阶压力分解。通过这些测试只能说明公式实现一致，不能证明模型能预测市场。
